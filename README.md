# Дневник психоэмоционального состояния

Исходный код к выпускной квалификационной работе «Проектирование и разработка мобильной информационной системы мониторинга психоэмоционального состояния пользователя с интеллектуальным анализом текстовых записей» (ПГНИУ, 2026).

Приложение для iPhone помогает вести дневник состояния между консультациями: оценки тревоги, настроения и энергии утром, днём и вечером, свободные и голосовые записи, учёт препаратов и PDF-отчёт для врача. Языковая модель предлагает признаки из записи по закрытому словарю с точной цитатой, отрицанием и временем; в статистику признак попадает только после подтверждения пользователем, а показатели и сравнения вычисляет код.

Система не ставит диагнозов, не подбирает дозы и не является медицинским изделием. Все данные в репозитории синтетические.

## Структура

```text
.
├── backend/     сервер: Java 25, Spring Boot, PostgreSQL, Liquibase
├── mobile/      приложение для iPhone: React Native, Expo, TypeScript; виджет на Swift
├── infra/       Docker Compose, сервис распознавания речи GigaAM, развёртывание
├── research/    наборы данных, скрипты экспериментов, ответы моделей и метрики
└── docs/        архитектура и API сервера, схемы PlantUML
```

## Проверка

```shell
cd backend && mvn clean verify                        # модульные тесты, порог JaCoCo 80 %
cd backend && mvn clean verify -Pintegration-tests    # интеграционные сценарии, нужен Docker
cd mobile && npm install && npm run test:coverage     # тесты приложения
cd research && python3 -m pytest -q                   # тесты метрик
```

Подробности запуска — в README каждого каталога.
