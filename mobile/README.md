# Мобильный клиент

React Native 0.88 + Expo SDK 58, TypeScript (strict), Expo Router (нативные табы), TanStack Query, Zustand, React Hook Form + Zod. Только iPhone. Требования и правила — [docs/PROJECT.md](../docs/PROJECT.md), контракт сервера — [docs/backend/api.md](../docs/backend/api.md).

## Запуск

```sh
cd mobile
npm install
EXPO_PUBLIC_API_URL=http://<адрес-Mac>:8080/api/v1 npx expo run:ios
```

Если CocoaPods падает с `Unicode Normalization`, выполните `export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8`. Адрес бэкенда можно положить в игнорируемый `mobile/.env.local` (`EXPO_PUBLIC_API_URL=...`); по умолчанию `http://localhost:8080/api/v1` (подходит для Simulator). Для физического iPhone указывается IP Mac в локальной сети; HTTP разрешён только для локальной сети (`NSAllowsLocalNetworking`).

Если после правки в Simulator ничего не меняется, перезапустите Metro: `npx expo start --dev-client --clear`. Без `watchman` Metro может не замечать изменения файлов (на macOS его ставит `brew install watchman`).

## Проверки

```sh
npm run typecheck
npm run lint
npm run test:coverage   # порог: 80% строк и функций, 75% веток
```

## Иконка и splash

Исходник — скрипт `scripts/render-icons.py` (Pillow: `pip install pillow`). `python3 scripts/render-icons.py` пересоздаёт `assets/images/icon*.png` и `splash-icon*.png`. Иконка и splash — нативные ресурсы: после изменения нужна пересборка (`npx expo prebuild --platform ios && npx expo run:ios`), Metro их не подхватит.

## Виджет и Control «Новая запись»

Нативные таргеты лежат в `targets/quick-entry` (Swift, подключаются плагином `@bacons/apple-targets`): виджет на домашний экран (малый) и на экран блокировки, плюс Control для Пункта управления, экрана блокировки и Action button (iOS 18+). Все открывают приложение по ссылке `diary://entry/new`; без входа сначала показывается вход, затем «Новая запись» (`lib/native-intent.ts`, `features/quick-actions`).

Особенности:
- Control вызывает `OpenQuickEntryIntent`. Его файл `QuickEntryIntent.swift` должен входить и в таргет виджета, и в таргет приложения (метаданные App Intents ищутся в приложении), поэтому плагин `plugins/with-quick-entry-intent.js` копирует его в `ios/` и подключает к приложению. `OpenURLIntent` с собственной схемой `diary://` приложение не открывает, поэтому `perform()` в процессе приложения сам вызывает `UIApplication.open` (код под флагом `QUICK_ENTRY_APP`, который плагин ставит только на таргет приложения).
- Таргет виджета собирается под iOS 18.0; приложение по-прежнему поддерживает 16.4, но виджета на этих версиях не будет.
- После правки `targets/`, `plugins/` или `app.json`: `npx expo prebuild --platform ios --clean && npx expo run:ios`. Плагин предупреждает об отсутствии `ios.appleTeamId`: для Simulator это не мешало, для устройства team нужен.
- Добавить виджет в Simulator: долгое нажатие на иконку «Дневник» и выбор размера; Control: Пункт управления → «+» → раздел «Дневник» (в поиск Simulator кириллица не вводится, раздел находится прокруткой).

## Слои `src/`

| Каталог | Назначение |
| --- | --- |
| `app/` | Только маршруты Expo Router; `(auth)` — вход, `(tabs)` — Сегодня, Дневник, Динамика, Настройки |
| `screens/` | Тела экранов, которые рендерят маршруты |
| `components/` | Общие UI-компоненты без бизнес-логики |
| `api/` | HTTP-клиент (таймаут, problem+json, повтор после обновления токена), вызовы API, типы |
| `auth/` | Сессия: refresh-токен в Keychain, access в памяти, единый refresh на параллельные запросы |
| `hooks/`, `lib/`, `config/`, `theme/` | Запросы данных, утилиты, окружение, дизайн-токены |

## Состояние

Реализованы: вход, регистрация, выход; оценки по слотам; записи (черновик, лента, правка, удаление, календарь, день); AI-проверка тегов и ручная разметка выделением текста; препараты, версии схем, отметки приёма, внеплановый приём, локальные напоминания; динамика, график, сравнение дней с тегом и без; отчёт для врача и PDF через системный Share; настройки (профиль, тема, AI и голос, напоминания, экспорт и удаление данных); голосовая диктовка (запись WAV PCM16 16 кГц моно). Онбординг из четырёх страниц с анимированными макетами (до входа, один раз; повтор в «Настройки → Знакомство с приложением»; уважает «Уменьшить движение»). Иконка (light, dark, tinted) и splash свои, не шаблонные. Виджет и Control «Новая запись». Элементы управления на Liquid Glass с запасным вариантом при «Уменьшить прозрачность». Типы API описаны вручную по DTO бэкенда; после запуска бэкенда с профилем `local` их можно заменить генерацией из OpenAPI.

Приложение проверено в iOS Simulator с развёрнутым сервером, включая сквозной сценарий с подключёнными моделями: анализ записи и подтверждение тегов, диктовку и отчёт с PDF. На физическом iPhone приложение не проверялось.
